# 정책 톡톡 💡 — AI 매칭 서비스

> 인공지능개론 4차 과제 | 작성 일자: 2025.12.04

복잡한 정책 공고문을 AI가 분석하고, 나에게 딱 맞는 청년 정책을 추천해주는 **AI 정책 매칭 서비스**입니다.

---

## 📌 문제 제기 (Why?)

**왜 청년들은 혜택을 놓치는가?**

1. **정보의 홍수**: 정책은 많은데 나에게 맞는 걸 찾기 힘듦 (PDF, HWP 공고문의 압박)
2. **복잡한 자격 요건**: 연소득, 만 나이, 세대주 여부 등 조건이 너무 까다로움
3. **결과**: "몰라서 못 받는" 지원금 발생

---

## 🚀 서비스 소개 (What?)

**해결책**: 내 조건만 입력하면 AI가 공고문을 분석해 매칭해주는 서비스

### 핵심 기능
- **초개인화 매칭**: 나이, 소득, 자산 3가지 핵심 데이터로 1초 만에 판별
- **AI 공고 분석**: 비정형 텍스트(공고문)를 정형 데이터(DB)로 자동 변환
- **MVP 모델**: 가장 인기 있는 청년 주거 정책 5종 탑재

### 사용 방법
1. 만 나이, 연소득(만원), 무주택 여부 입력
2. "AI가 나에게 맞는 정책 추천받기" 버튼 클릭
3. 정책 분석 후 나에게 맞는 추천 결과 확인

---

## 🛠️ 개발 과정 (How?)

### 백엔드 영역

| 단계 | 내용 |
|---|---|
| 1. AI 툴 활용 | Gemini & ChatGPT를 적극 활용하여 백엔드 로직 설계 |
| 2. 크롤링 환경 구축 | 가상 환경 구축 및 라이브러리 설치로 크롤링 코드 실행 준비 |
| 3. 크롤링 코드 작성 | `policy_crawler_project` 폴더 생성 후 크롤링 코드 작성 및 저장 |
| 4. 텍스트 확보 & NLP 설계 | `raw_policy_text_1.txt`로 텍스트 확보 → ChatGPT로 NLP 로직 설계 (7가지 태그별 Regex 패턴) |
| 5. NLP 분석 & DB 구조화 | 파일 읽기 → 패턴 정의 → 패턴 검색/추출 → 후처리·정형화 → 정책 지식 DB 구축 |
| 6. AI 매칭 로직 & API 구축 | 7가지 분석 태그(Income, Age, Asset 등) 기반 매칭 코드 작성, **FastAPI**로 API 서버 구현 및 실행 테스트 완료 |

### 프론트엔드 영역

- **로고 생성**: 미리캔버스의 AI 툴을 활용해 홈페이지 로고 제작
- **홈페이지 구현**: HTML/JS 기반 UI 구성 (나이/소득/무주택 여부 입력 폼 + 추천 결과 표시)

### 배포 과정에서의 문제와 해결

- 백엔드 서버 배포를 위해 **Render**로 API를 연결했지만 계속 오류 발생 (CORS, Git, 환경 변수 등)
- 결국 크롤링 결과를 HTML 코드에 직접 옮기는 방식으로 전환
- **최종 전략**: 복잡한 API 연결 대신, 모든 데이터와 로직을 HTML 파일 안의 JavaScript로 통합하여 단순화 — 가장 빠르고 확실한 해결책이었음
- **Netlify & GitHub**을 통해 최종 사이트 배포 성공

---

## 🎬 시연

- 만 나이 / 연소득 / 무주택 여부를 입력하면 AI가 정책을 분석
- 분석 중 로딩 화면(⏳) → 추천 완료(✨) 또는 매칭 실패(❌) 안내
- 조건에 맞는 청년 주거 정책 추천 결과를 리스트로 제공

---

## 💡 느낀점 및 개인적 COMMENT(교훈)

- **환경 차이**: 로컬(VS Code)에서 잘 돌아가도 클라우드 서버(Render)로 옮기면 설정 문제로 오류 발생 (CORS, Git, 환경 변수 등)
- **연결의 고통**: 서버(Render)와 웹페이지(Netlify)를 분리하면 통신을 위한 CORS 등 보안 문제를 반드시 해결해야 함
- **최종 전략**: 복잡한 API 연결 대신 모든 로직을 HTML 내 JavaScript로 통합하는 것이 가장 빠르고 확실한 해결책이었음
- 다만 API 연동해서 시도해보고 싶음 - 실제 개발에서는 API 연동이 정말 많이 쓰이니까...?
- 결과는 맘에 들지 않음. 다만 백엔드에 대해 약간 찾아볼 수 있던 계기
